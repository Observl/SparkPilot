# 初燃 SparkPilot

企业冷启动策略与实验工作台。当前版本不接入 AI：使用可解释的自评规则和固定策略模板，完成从企业建档到实验复盘的闭环。

## 本地运行

需要 Node.js 20 或以上，无需安装第三方依赖。

```sh
node server.mjs
```

打开 http://127.0.0.1:5173 。支持 `PORT` 环境变量，也可使用 `npm run dev`。默认仅监听本机。

## MVP 功能

- 多项目切换、空白项目创建和明确标识的示例项目。
- 企业档案：客群、产品、价值主张、负责人和预算。
- 五维自评诊断与透明的策略推荐规则。
- 三种策略模板，可编辑配套实验。
- 实验创建、编辑、删除、状态筛选、目标与实际支出记录。
- 手工证据库，记录来源、日期、观察与假设。
- 完成实验后对照目标，记录学习和下一步行动。
- 全工作空间 JSON 导入导出，导入前校验并确认替换。
- 中文界面、紫色强调色、移动端适配、原生可访问表单与弹窗。

## 市场信息流与冷启动数据

导航新增「市场信息流」和「经营数据」。

- 信息流聚合所有项目的市场信息和原证据库记录，按**原始发布时间倒序**排列，日期未知置底；入库日期不替代发布时间。可搜索标题、正文、来源和项目，筛选项目、采集方式和时效状态。
- 人工录入或 CSV 导入市场消息，保存来源、链接、地区、信息性质、原文核对声明、独立佐证与冲突情况。AI 标签表示外部 AI 采集的记录，**不代表本应用已接入 AI 或自动核实内容**。
- 内容规则识别促销价格、舆情、竞品、政策、渠道和研究；优先参考明确截止日，支持从正文「截止2026年10月23日」等表述提取日期。自动提取结果仍需人工检查适用对象。
- 默认复核窗口：舆情 2 天；促销和未分类 7 天；竞品、渠道和政策 30 天；客户研究 90 天；行业研究 180 天。手工截止日覆盖正文提取日；截止日与复核窗口取更早者。到期指需要复核，不代表历史事实失真，也不保证期间内没有变化。
- 可靠性分为待核查、中等依据、较强依据、存在冲突、观点 / 假设。来源标签或 AI 标签不直接带来高可靠性；较强依据需记录者声明核对原文、一手来源类型和独立佐证记录。等级是可解释的元数据检查，非真实性认证或概率。
- 企业档案新增启动背景、客户角色、交付能力、单位经济、资金资源、市场环境与证据口径的折叠表单。空白保持未知，零值与缺失值区分。
- 经营指标支持手填或 CSV 导入访问、咨询、试用、激活、付款、退款、复购、留存，保留周期、分母、来源和客群；不跨期拼接漏斗。根据填写数据展示单笔贡献额和静态现金支撑月数。

### CSV 约定

两个页面均提供可下载的模板。使用 UTF-8 CSV，支持 BOM、带引号的逗号、换行和双引号。单次不超过 5MB / 2000 行。先完整校验，再预览确认追加；错误文件不写入，完全重复记录跳过。市场信息追加到当前项目。日期使用 `YYYY-MM-DD`。

市场信息列：`title,note,source,url,publishedAt,validUntil,category,origin,sourceType,verification,region,kind,conflict,corroboration,corroborationSources`。标题、正文、来源必填，其余可省略。origin 为「人工」或「AI」。verification 为「未核对」或「已核对原文」。示例模板不代表真实资料。

经营数据列：`metric,value,denominator,periodStart,periodEnd,source,segment`。指标、非负整数数值、起止日期、来源必填；分母与客群选填。留存和复购的分母应来自同一队列。

### 评估原则

参考 [ISO/IEC 25012 数据质量模型](https://www.iso.org/standard/35736.html) 的质量评估思路与 [W3C PROV](https://www.w3.org/TR/prov-overview/) 的来源追溯原则。这里的分类规则、可靠性等级与复核天数是本产品设计，**并非这些标准规定的阈值或认证**。不存在适用于所有行业的「全球大型企业统一商业达标线」；无法判断的数据不以虚构行业均值填补。

旧版备份仍可导入，新字段作为可选扩展保存；新备份包含背景、市场信息与经营指标。

## 验证

```sh
node --test tests/domain.test.mjs
node --test tests/market.test.mjs
node --check app.js
node --check domain.js
```

`tests/browser-smoke.cjs` 和 `tests/market-browser.cjs` 提供实际浏览器流程测试，需要可用的 Playwright 和本机 Edge。可通过 `PLAYWRIGHT_MODULE` 指定模块路径，`TEST_URL` 指定运行中的应用地址（默认 5180 端口）。

## 数据边界

本版无账号、服务端数据库、云端同步或自动市场研究。数据存储在当前站点的 localStorage；更换浏览器、端口、设备或清理站点数据不会保留原数据，请定期导出。示例内容不代表真实研究。诊断得分是准备度检查，不是成功概率。预算为可编辑模板示例。

## 项目结构

- `app.js`：页面与交互。
- `domain.js`：诊断、推荐、备份校验与初始数据。
- `market.js`：时效、可靠性、背景字段、CSV 解析与扩展校验。
- `workspace.js`：市场信息流、经营指标和新增录入交互。
- `styles.css`：响应式紫色界面。
- `server.mjs`：本地静态预览。
- `tests/`：规则与数据校验测试。

后续可在现有企业、证据、假设和实验结构上接入身份验证、数据库与 AI 服务层。
